# PDV / Frente de Caixa — Sistema Veronica — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the PDV (point-of-sale) sub-project: a shared cash-register session used by multiple operators at once, presencial sales with manual (Dinheiro/Débito/Crédito) and real Pix (Mercado Pago) payment, and cash-register closing with a per-operator breakdown.

**Architecture:** Same procedural PHP 8.5 style as the Fundação sub-project (page-per-file, `conecta_bd.php` + `includes/auth.php`, no framework). A shared `includes/caixa.php` holds the sale/cash-register business logic (`finalizarVenda`, stock-locking, cash-register lookups), reused by the manual "Finalizar" button, the Pix polling endpoint, and the Pix webhook — so stock debit/payment recording never gets duplicated across three code paths. Mercado Pago integration is raw cURL against MP's REST API (`v1/payments`, `checkout/preferences`-free — this sub-project only uses the direct Payments API for Pix — and `oauth/token`), matching the `sys01` reference project's own `caixa/` module, not the Composer SDK.

**Tech Stack:** PHP 8.5, MySQL 8 (InnoDB, utf8mb4), PDO, native PHP sessions, cURL (bundled `ext-curl`), Mercado Pago REST API (Payments + OAuth).

**Spec:** [docs/superpowers/specs/2026-09-09-pdv-design.md](../specs/2026-09-09-pdv-design.md)

## Global Constraints

- No automated tests — every task's verification step is a manual procedure (curl + direct DB queries against a real running server) to run and observe, matching the Fundação sub-project's convention.
- Money fields are `DECIMAL(10,2)`; every place a Brazilian comma-decimal string enters PHP from a form, it is normalized with `str_replace(',', '.', $value)` **before** the `(float)` cast — this exact bug (missing normalization) was found and fixed twice during the Fundação sub-project, so get it right the first time here.
- The cash-register session (`caixa_sessoes`) is **shared** across operators, not per-user: at most one `status = 'aberto'` row exists system-wide at a time; any logged-in user (Admin or Funcionário) can open it, sell against it, and close it. Every sale records which operator made it (`vendas.id_usuario`).
- `itens_venda` never holds a foreign key to `produtos`/`produto_variacoes` — it stores a snapshot (`nome_produto`, `descricao_combinacao`, `preco_unit`) taken at the moment the item is added, plus a **soft, unenforced** `id_produto_variacao` reference used only to locate the stock row to debit at finalization time. This matches the Fundação sub-project's decision that products must always be physically deletable without breaking sale history.
- `marketplace_fee`/`application_fee` of 1% (`ceil($valor * 0.01 * 100) / 100`) and `sponsor_id: 194420711` apply to **every** Mercado Pago charge this sub-project creates, including direct Pix payments (`v1/payments`, field name `application_fee`) — this closes a gap found in the `sys01` reference code, where only the Checkout-Pro "Link" flow (not built in this sub-project) applies the fee on Pix. Confirmed with the project owner.
- Mercado Pago **application-level** credentials (`MP_APP_CLIENT_ID`, `MP_APP_CLIENT_SECRET`, `MP_WEBHOOK_SECRET`) are PHP constants defined in `brechodaveve_config_credenciais.php` (outside the web root, never committed) — they belong to the CoderNex OAuth application, not to this store. The store's **own** Mercado Pago credentials (`mp_access_token`, obtained via OAuth) live in the `config_pagamento` database table — they're the store's own business data, not CoderNex's.
- OAuth redirect URI is fixed: `https://brechodaveve.codernex.com.br/integracoes/mercado_pago/callback.php`.
- All PDO connections and money-handling conventions established in the Fundação sub-project continue to apply (bound parameters everywhere, `htmlspecialchars()` on all dynamic HTML output, exceptions propagate rather than being echoed raw).
- Every endpoint that reads or mutates a specific `id_venda` while a real user session exists (adding/removing cart items, linking a client, viewing/paying the cart, generating or polling a Pix charge) must scope its `vendas` lookup to `id_usuario = $_SESSION['id_usuario']` — the shared caixa session means multiple operators are logged in at once, and without this scoping one operator can view or act on another operator's in-progress sale by guessing a sequential `id_venda` (a real IDOR found and fixed during this sub-project's own review). The one deliberate exception is `finalizarVenda()` itself (`includes/caixa.php`, Task 1), which must stay unscoped by `id_usuario` because it's also called from the Pix webhook and polling, where no operator session exists — ownership is instead checked by the AJAX wrapper (`caixa/ajax/finalizar_venda.php`) before it calls `finalizarVenda()`. `caixa/comprovante.php` (a finished-sale receipt) is also deliberately left unscoped — any staff member may legitimately need to view or print a completed sale's receipt.

```php
<?php

function caixaAbertoAtual(PDO $pdo): ?array
{
    $stmt = $pdo->query("SELECT * FROM caixa_sessoes WHERE status = 'aberto' ORDER BY data_abertura DESC LIMIT 1");
    $row = $stmt->fetch();
    return $row ?: null;
}

function exigirCaixaAberto(PDO $pdo, bool $modo_json = false): array
{
    $caixa = caixaAbertoAtual($pdo);
    if (!$caixa) {
        if ($modo_json) {
            header('Content-Type: application/json');
            echo json_encode(['success' => false, 'message' => 'Nenhum caixa aberto.']);
        } else {
            header('Location: /caixa/abertura.php');
        }
        exit;
    }
    return $caixa;
}

function buscarVendaReservadaDoOperador(PDO $pdo, int $id_caixa, int $id_usuario): ?int
{
    $stmt = $pdo->prepare(
        "SELECT id_venda FROM vendas
         WHERE id_caixa = :ic AND id_usuario = :iu AND status = 'Reservado'
         ORDER BY data_venda DESC LIMIT 1"
    );
    $stmt->execute([':ic' => $id_caixa, ':iu' => $id_usuario]);
    $id = $stmt->fetchColumn();
    return $id ? (int) $id : null;
}

function recalcularTotalVenda(PDO $pdo, int $id_venda): float
{
    $stmt = $pdo->prepare('SELECT COALESCE(SUM(subtotal), 0) FROM itens_venda WHERE id_venda = :id');
    $stmt->execute([':id' => $id_venda]);
    $total = (float) $stmt->fetchColumn();
    $pdo->prepare('UPDATE vendas SET valor_total = :total WHERE id_venda = :id')
        ->execute([':total' => $total, ':id' => $id_venda]);
    return $total;
}

/**
 * Núcleo de finalização de venda — reaproveitado pelo botão "Finalizar" (pagamento
 * manual), pelo polling do Pix e pelo webhook do Mercado Pago, pra nunca duplicar a
 * baixa de estoque/gravação de pagamento em mais de um lugar.
 *
 * $pagamentos: array de ['forma' => string, 'valor' => float]
 */
function finalizarVenda(PDO $pdo, int $id_venda, array $pagamentos, ?string $id_pagamento_mp = null): array
{
    if (empty($pagamentos)) {
        return ['success' => false, 'message' => 'Informe ao menos uma forma de pagamento.', 'redirect' => null];
    }

    try {
        $pdo->beginTransaction();

        $stmt = $pdo->prepare('SELECT valor_total, status FROM vendas WHERE id_venda = :id FOR UPDATE');
        $stmt->execute([':id' => $id_venda]);
        $venda = $stmt->fetch();

        if (!$venda || $venda['status'] !== 'Reservado') {
            throw new Exception('Venda não encontrada ou já finalizada.');
        }

        $total_pago = 0.0;
        foreach ($pagamentos as $pag) {
            $total_pago += (float) $pag['valor'];
        }
        if ($total_pago < (float) $venda['valor_total'] - 0.01) {
            throw new Exception('Valor pago insuficiente.');
        }

        $itens = $pdo->prepare('SELECT id_produto_variacao, quantidade FROM itens_venda WHERE id_venda = :id');
        $itens->execute([':id' => $id_venda]);
        $listaItens = $itens->fetchAll();

        if (empty($listaItens)) {
            throw new Exception('Não é possível finalizar uma venda sem itens.');
        }

        foreach ($listaItens as $item) {
            if ($item['id_produto_variacao'] === null) {
                continue;
            }
            $stmtPv = $pdo->prepare('SELECT estoque FROM produto_variacoes WHERE id_produto_variacao = :id FOR UPDATE');
            $stmtPv->execute([':id' => $item['id_produto_variacao']]);
            $pv = $stmtPv->fetch();
            if (!$pv || $pv['estoque'] < $item['quantidade']) {
                throw new Exception('Estoque insuficiente para um dos itens da venda.');
            }
        }

        foreach ($listaItens as $item) {
            if ($item['id_produto_variacao'] === null) {
                continue;
            }
            $pdo->prepare('UPDATE produto_variacoes SET estoque = estoque - :qtd WHERE id_produto_variacao = :id')
                ->execute([':qtd' => $item['quantidade'], ':id' => $item['id_produto_variacao']]);
        }

        $formas = [];
        foreach ($pagamentos as $pag) {
            $pdo->prepare('INSERT INTO venda_pagamentos (id_venda, forma_pagamento, valor) VALUES (:id, :forma, :valor)')
                ->execute([':id' => $id_venda, ':forma' => $pag['forma'], ':valor' => $pag['valor']]);
            $formas[] = $pag['forma'];
        }
        $forma_pagamento = count(array_unique($formas)) > 1 ? 'Mista' : $formas[0];

        $pdo->prepare('UPDATE vendas SET status = "Pago", forma_pagamento = :forma, id_pagamento_mp = :idmp WHERE id_venda = :id')
            ->execute([':forma' => $forma_pagamento, ':idmp' => $id_pagamento_mp, ':id' => $id_venda]);

        $pdo->commit();

        return [
            'success' => true,
            'message' => 'Venda finalizada com sucesso.',
            'redirect' => '/caixa/comprovante.php?id_venda=' . $id_venda,
        ];
    } catch (Throwable $e) {
        if ($pdo->inTransaction()) {
            $pdo->rollBack();
        }
        return ['success' => false, 'message' => $e->getMessage(), 'redirect' => null];
    }
}
```

```php
<?php
require_once __DIR__ . '/../../conecta_bd.php';
require_once __DIR__ . '/../../includes/auth.php';
exigirLogin();
header('Content-Type: application/json');

$termo = trim($_GET['termo'] ?? '');
if ($termo === '') {
    echo json_encode(['produtos' => []]);
    exit;
}

$stmt = $pdo->prepare(
    'SELECT pv.id_produto_variacao, p.nome AS nome_produto,
            GROUP_CONCAT(vv.valor SEPARATOR " / ") AS descricao_combinacao,
            COALESCE(pv.preco, p.preco_base) AS preco, pv.estoque
     FROM produto_variacoes pv
     JOIN produtos p ON p.id_produto = pv.id_produto
     LEFT JOIN produto_variacao_valores pvv ON pvv.id_produto_variacao = pv.id_produto_variacao
     LEFT JOIN variacao_valores vv ON vv.id_valor = pvv.id_valor
     WHERE p.ativo = 1 AND pv.estoque > 0 AND p.nome LIKE :termo
     GROUP BY pv.id_produto_variacao, p.nome, pv.preco, p.preco_base, pv.estoque
     ORDER BY p.nome
     LIMIT 20'
);
$stmt->execute([':termo' => '%' . $termo . '%']);
$produtos = $stmt->fetchAll();

foreach ($produtos as &$p) {
    $p['nome_completo'] = $p['nome_produto'] . ($p['descricao_combinacao'] ? ' (' . $p['descricao_combinacao'] . ')' : '');
    $p['preco'] = (float) $p['preco'];
    $p['estoque'] = (int) $p['estoque'];
}
unset($p);

echo json_encode(['produtos' => $produtos]);
```

$id_produto_variacao = (int) ($_POST['id_produto_variacao'] ?? 0);
$quantidade = max(1, (int) ($_POST['quantidade'] ?? 1));

$stmtV = $pdo->prepare("SELECT id_venda FROM vendas WHERE id_venda = :id AND id_usuario = :iu AND status = 'Reservado'");
$stmtV->execute([':id' => $id_venda, ':iu' => $_SESSION['id_usuario']]);
if (!$stmtV->fetch()) {
    echo json_encode(['success' => false, 'message' => 'Venda não encontrada ou já finalizada.']);
    exit;
}

$stmt = $pdo->prepare(
    'SELECT pv.estoque, COALESCE(pv.preco, p.preco_base) AS preco, p.nome AS nome_produto,
            GROUP_CONCAT(vv.valor SEPARATOR " / ") AS descricao_combinacao
     FROM produto_variacoes pv
     JOIN produtos p ON p.id_produto = pv.id_produto
     LEFT JOIN produto_variacao_valores pvv ON pvv.id_produto_variacao = pv.id_produto_variacao
     LEFT JOIN variacao_valores vv ON vv.id_valor = pvv.id_valor
     WHERE pv.id_produto_variacao = :id
     GROUP BY pv.estoque, pv.preco, p.preco_base, p.nome'
);
$stmt->execute([':id' => $id_produto_variacao]);
$produto = $stmt->fetch();

if (!$produto) {
    echo json_encode(['success' => false, 'message' => 'Produto não encontrado.']);
    exit;
}

if ($produto['estoque'] < $quantidade) {
    echo json_encode(['success' => false, 'message' => 'Estoque insuficiente (disponível: ' . $produto['estoque'] . ').']);
    exit;
}

$preco_unit = (float) $produto['preco'];
$subtotal = $preco_unit * $quantidade;

$pdo->prepare(
    'INSERT INTO itens_venda (id_venda, nome_produto, descricao_combinacao, id_produto_variacao, quantidade, preco_unit, subtotal)
     VALUES (:iv, :nome, :desc, :ipv, :qtd, :preco, :subtotal)'
)->execute([
    ':iv' => $id_venda,
    ':nome' => $produto['nome_produto'],
    ':desc' => $produto['descricao_combinacao'] ?: null,
    ':ipv' => $id_produto_variacao,
    ':qtd' => $quantidade,
    ':preco' => $preco_unit,
    ':subtotal' => $subtotal,
]);

recalcularTotalVenda($pdo, $id_venda);

echo json_encode(['success' => true]);

function mpConfig(PDO $pdo): ?array
{
    $stmt = $pdo->query('SELECT * FROM config_pagamento WHERE id_config = 1');
    return $stmt->fetch() ?: null;
}

/**
 * Chamada genérica à API do Mercado Pago. $metodo é 'GET' ou 'POST'.
 */
function mpChamarApi(string $metodo, string $url, ?array $payload, string $access_token, array $headersExtra = []): array
{
    $headers = array_merge([
        'Content-Type: application/json',
        'Authorization: Bearer ' . $access_token,
    ], $headersExtra);

    $opts = [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER => $headers,
        CURLOPT_TIMEOUT => 15,
    ];
    if ($metodo === 'POST') {
        $opts[CURLOPT_POST] = true;
        $opts[CURLOPT_POSTFIELDS] = json_encode($payload);
    }

    $ch = curl_init($url);
    curl_setopt_array($ch, $opts);
    $resposta = curl_exec($ch);
    $http_code = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    $erro = curl_error($ch);
    curl_close($ch);

    if ($resposta === false) {
        throw new Exception('Erro de conexão com o Mercado Pago: ' . $erro);
    }

    return ['http_code' => $http_code, 'dados' => json_decode($resposta, true)];
}

```php
/**
 * Valida a assinatura X-Signature do webhook do Mercado Pago.
 * Formato do header: "ts=<timestamp>,v1=<hash>"
 * Manifesto: "id:{dataId};request-id:{xRequestId};ts:{ts};" (dataId em minúsculas)
 */
function mpValidarAssinaturaWebhook(string $xSignature, string $xRequestId, string $dataId, string $secret): bool
{
    $partes = [];
    foreach (explode(',', $xSignature) as $par) {
        $dividido = explode('=', trim($par), 2);
        if (count($dividido) === 2) {
            $partes[trim($dividido[0])] = trim($dividido[1]);
        }
    }

    $ts = $partes['ts'] ?? null;
    $v1 = $partes['v1'] ?? null;
    if (!$ts || !$v1) {
        return false;
    }

    $manifesto = "id:{$dataId};request-id:{$xRequestId};ts:{$ts};";
    $hash = hash_hmac('sha256', $manifesto, $secret);

    return hash_equals($hash, $v1);
}
```
